# 개발 로드맵

## 1차 — 기반 구조
- React/Vite/TypeScript 앱, Supabase 로그인과 역할 확인
- 그룹형 사이드바, 반응형 페이지 구조, PWA

## 2차 — 조사 설계
- 조사 전용 데이터베이스의 schema·RLS·권한 검토
- 조사 생성·수정·목록, 참여자 지정, 질문과 응답 유형
- 검토 후 두드림 난타 기본 조사 준비

## 3차 — 현장 진행
- 조사 진행, 이용인 사진 선택, 응답 저장
- 직원 지원 모드와 완료 현황

## 4차 — 분석
- 사전·사후 비교, 결과 분석, 조사 기록 검색, 보고서와 인쇄

## 5차 — 개선
- 실제 사용 결과에 따른 UI·기능 개선
- 템플릿 관리와 관리자 기능

## 두드림 난타 조사 계획

- **사전·사후 비교조사:** 자기표현과 사회적 상호작용을 동일 문항으로 사전·사후 비교
- **공연 후 단회조사:** 공연 만족감, 성취감, 자신감

1차에서는 위 내용을 계획으로만 기록하며 DB에 어떠한 기본 조사 데이터도 생성하지 않습니다. 2차에서 schema, 권한, 개인정보 보호 방식을 검토한 뒤 안전하게 추가합니다.
